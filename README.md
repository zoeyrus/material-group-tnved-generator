# material-group-tnved-generator

Приложение с графическим интерфейсом для формирования двух JSON-файлов с SQL-запросами из XLS, XLSX или CSV.

## Использование

1. Запустите `TNVED_JSON.exe`.
2. Выберите таблицу: первая колонка — код товарной группы, вторая — код ТН ВЭД.
3. Укажите наличие заголовков и номер листа Excel, при необходимости измените папку и имена файлов.
4. Нажмите **«Создать два JSON-файла»**.

Результат:

- `INSERT INTO material.material_group_tnved.json` — добавление уникальных связок групп и ТН ВЭД.
- `INSERT INTO material.material_tnved.json` — добавление уникальных ТН ВЭД с проверкой `WHERE NOT EXISTS`.

Каждый JSON содержит массив SQL-строк. Приложение не выполняет запросы в базе. Сначала выполняются запросы справочника ТН ВЭД, затем связок. Для связок проверки существования в базе нет.

Повторы во входной таблице удаляются. ТН ВЭД короче 10 цифр дополняется нулями слева; рекомендуется хранить коды в таблице как текст. По умолчанию первая строка считается заголовком.

## Сборка Windows EXE

**GitHub:** откройте **Actions → Build Windows EXE**, выберите успешную сборку и скачайте **Artifacts → TNVED_JSON-Windows**. Распакуйте архив и запустите EXE.

**Локально:** установите Python 3.10+ с Python Launcher и запустите `build_windows.bat`. Для сборки нужен интернет. Результат — `dist/TNVED_JSON.exe`; для его запуска Python не требуется.

Запуск исходника:

```bash
python -m pip install -r requirements.txt
python tnved_json.py
```
