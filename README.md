# material-group-tnved-generator

Приложение для создания SQL-запросов из XLS, XLSX и CSV.

## Использование

1. Запустите `TNVED_JSON.exe` и выберите таблицу: первая колонка – код группы, вторая – ТН ВЭД.
2. Выберите формат **JSON / SQL** и количество файлов: **один / два**.
3. Укажите заголовки, номер листа Excel, папку и имена результата.
4. Нажмите **«Создать файлы»**.

В одном файле сначала идёт справочник ТН ВЭД, затем связки групп.
В двух файлах используются имена `INSERT INTO material.material_tnved` и `INSERT INTO material.material_group_tnved`.
Имя объединённого файла – `tnved_and_group_tnved`. Имена можно менять, расширение выбирается автоматически.

JSON содержит массив SQL-строк; SQL – готовый текст запросов с комментариями.
Справочник заполняется через `WHERE NOT EXISTS`, связки – с `ON CONFLICT DO NOTHING` (PostgreSQL).
Пропуск конфликта зависит от ограничений базы: без уникального ограничения на связку дубли в базе не предотвращаются.
Программа не подключается к базе и не выполняет запросы.

Повторы во входной таблице удаляются. ТН ВЭД короче 10 цифр дополняется нулями слева.
Коды рекомендуется хранить как текст. По умолчанию первая строка – заголовки.

## Скачать или собрать

Готовый EXE: [Releases](https://github.com/zoeyrus/material-group-tnved-generator/releases/latest).
Для запуска Python не нужен.

Локальная сборка: Python 3.10+ с Python Launcher → `build_windows.bat`.
Нужен интернет; результат – `dist/TNVED_JSON.exe`.

Запуск исходника:

```bash
python -m pip install -r requirements.txt
python tnved_json.py
```
